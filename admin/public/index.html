Database backups use pg_dump (custom format) and are verified with pg_restore --list. Restore (history and config) is done from the Restore button; it requires typing RESTORE, needs the backend stopped, takes a safety backup first and rolls back on failure. Full-database backups are restored from the command line: pg_restore --clean --if-exists --no-owner -d itr_market_data <file>. Configuration backups contain credentials; keep them private.
